Разберём зарезервированные и специальные IPv4-адреса по категориям.





## Link-local (APIPA)

**169.254.0.0/16** — диапазон 169.254.0.1 – 169.254.255.254.

- Хост назначает себе такой адрес **автоматически**, если не смог получить IP по DHCP.
- Работает только в пределах локального сегмента (не маршрутизируется).
- Признак проблемы: видишь 169.254.x.x — значит, DHCP не ответил.

## Multicast

**224.0.0.0/4** (класс D) — групповая рассылка.

- **224.0.0.1** — all hosts, **224.0.0.2** — all routers.
- **224.0.0.5 / 224.0.0.6** — OSPF; **224.0.0.9** — RIP.
- **239.0.0.0/8** — административно scoped multicast (внутри организации).

## Другие специальные

- **255.255.255.255** — ограниченный broadcast (см. выше).
- **240.0.0.0/4** (класс E) — зарезервировано, кроме 255.255.255.255.
- **192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24** — TEST-NET, для документации и примеров.
- **198.18.0.0/15** — для тестирования производительности сетей.
- **100.64.0.0/10** — CGNAT (carrier-grade NAT), общий диапазон для провайдерского NAT.

## Короткая шпаргалка

| Адрес/диапазон | Что это |
|---|---|
| 127.0.0.0/8 | loopback (localhost) |
| 192.168.1.255 | directed broadcast для /24 |
| 255.255.255.255 | limited broadcast |
| 0.0.0.0 | «любой/неизвестный» |
| 10/8, 172.16/12, 192.168/16 | private (RFC 1918) |
| 169.254.0.0/16 | link-local (APIPA) |
| 224.0.0.0/4 | multicast |
| 100.64.0.0/10 | CGNAT |
