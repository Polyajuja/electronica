# Сети: от локальной до глобальной — полный разбор

Собрал всё, что мы обсудили, в единую картину — от адресов до устройств.

---

## Часть 1. Адреса: локальные vs глобальные

### Ваша интуиция верна
У устройств внутри ЛВС — **свои (приватные) адреса**, а «внешний» (публичный) адрес — **только у маршрутизатора**.

### Как это устроено

| | Внутренний (приватный) IP | Внешний (публичный) IP |
| :--- | :--- | :--- |
| **У кого** | У каждого устройства в ЛВС | У роутера (выдаёт провайдер) |
| **Уникальность** | Не уникален в мире (такой же есть у соседа) | Уникален во всём мире |
| **Кто видит** | Только внутри вашей сети | Все сайты в интернете |
| **Примеры** | `192.168.x.x`, `10.x.x.x`, `172.16–31.x.x` | Что угодно, кроме приватных диапазонов |

### Как работает NAT (Network Address Translation)
1. Компьютер отправляет запрос роутеру.
2. Роутер **подменяет** внутренний адрес на свой внешний.
3. Сайт видит только внешний адрес роутера и отвечает ему.
4. Роутер **помнит**, какому устройству предназначался ответ, и пересылает обратно.

**Аналогия:** внешний IP — адрес многоквартирного дома (один на всех). Внутренние IP — номера квартир. Почтальон (интернет) знает только адрес дома, а по квартирам распределяет консьерж (роутер).

**Зачем так:** IPv4-адресов не хватает на все устройства мира, поэтому придумали систему с локальными сетями.

## Часть 2. Устройства: повторитель, мост, коммутатор, маршрутизатор

Различаются по **уровням модели OSI** — от «тупого» повторения сигнала до «умной» маршрутизации.

| Устройство | Уровень OSI | С чем работает | Главная функция |
| :--- | :--- | :--- | :--- |
| **Повторитель / Хаб** | L1 (Физический) | Электричество | Усилить сигнал, повторить во все порты |
| **Мост** | L2 (Канальный) | MAC-адреса | Соединить 2 сегмента, фильтровать мусор |
| **Коммутатор** | L2 (Канальный) | MAC-адреса | Многопортовая коммутация внутри одной сети |
| **Маршрутизатор** | L3 (Сетевой) | IP-адреса | Соединить разные сети, выбрать путь, NAT |

### Подробнее

**Повторитель / Хаб (L1)**
- Не понимает адресов вообще.
- Что пришло в один порт — разослал во все.
- Все порты в **одном домене коллизий**.
- Морально устарел.

**Мост (L2)**
- Работает с MAC-адресами.
- Исторически — устройство на **2 порта**.
- Соединяет два сегмента, фильтрует трафик между ними.
- Делит один «шумный» домен на два тихих.

**Коммутатор (L2, иногда L3)**
- **Многопортовый мост** (8, 16, 24, 48 портов).
- Изучает MAC-адреса, строит таблицу коммутации.
- Отправляет кадр **только в нужный порт**, а не во все.
- **Каждый порт = отдельный домен коллизий.**
- Есть **L3-коммутаторы** — умеют и коммутировать, и маршрутизировать.

**Маршрутизатор (L3)**
- Работает с IP-адресами.
- Соединяет **разные сети** (ЛВС ↔ интернет).
- Ведёт таблицу маршрутизации, выбирает путь.
- Выполняет NAT.
- Без него ЛВС была бы изолированным островом.

**Аналогия:**
- **Хаб** — крикун в комнате: сказал слово, услышали все.
- **Коммутатор** — секретарь: знает, кто где сидит, передаёт записку лично.
- **Маршрутизатор** — почтовое отделение: доставляет письма в другой город.

## Часть 3. Домен коллизий

**Домен коллизий** — зона сети, где устройства конкурируют за общую среду, и при одновременной передаче возникает конфликт (наложение сигналов).

- **Хаб** — все порты в **одном** домене коллизий.
- **Коммутатор** — **каждый порт = отдельный** домен коллизий.
- **Полный дуплекс** — коллизий вообще нет (передача и приём по разным парам проводов).

Это не «узлы на одной шине», а **логическая зона возможных конфликтов**. Раньше совпадала с физической шиной, теперь зависит от устройства.

---

## Часть 4. Мост vs Коммутатор

**По сути — одно и то же, эволюция.**

- **Мост** — 2 порта (или немного).
- **Коммутатор** — многопортовый мост, быстрее (аппаратная коммутация через ASIC).

Функция одна: учат MAC-адреса, фильтруют кадры, разделяют домены коллизий. Термин «мост» почти вышел из употребления.

## Часть 5. Что такое локальная сеть

ЛВС — это не просто «приватное пространство имён», а совокупность:

1. **Ограниченная территория** — квартира, офис, кампус.
2. **Своё адресное пространство** — приватные IP, не маршрутизируемые в интернете.
3. **Свой широковещательный домен** — broadcast не выходит наружу.
4. **Обычно один сегмент L2** — устройства видят MAC друг друга.

**Граница ЛВС** обычно проходит по маршрутизатору.

---

## Часть 6. Маршрутизатор: только для IP?

**Нет.** Маршрутизатор — это **роль** на L3, а не привязка к IP.

- **IP** — самый популярный L3-протокол, но не единственный.
- **IPX/SPX** (Novell) — свои маршрутизаторы.
- **AppleTalk** — свои.
- **MPLS** — маршрутизация по меткам.
- **ATM** — по виртуальным каналам.

**В любой технологии с логической адресацией есть свой «маршрутизатор».** Просто IP победил, и слово «роутер» почти всегда означает IP-маршрутизатор.

## Часть 7. Сводка: кто за что отвечает

| Вопрос | Ответ |
| :--- | :--- |
| Разница локальных и глобальных адресов | Приватные — внутри ЛВС, публичный — один у роутера |
| Домен коллизий | Зона конфликтов за среду. Хаб — один, коммутатор — на порт |
| Мост vs Коммутатор | Мост = 2 порта, коммутатор = много. Функция одна |
| Коммутатор только для ЛВС? | В основном да, но L3-коммутаторы умеют маршрутизировать |
| ЛВС — приватное пространство? | Да: приватные IP + broadcast-домен + граница |
| Маршрутизатор — для связи ЛВС? | Да, он переходит границы между сетями |
| Только поверх IP? | Нет, L3 бывает разный. IP просто победил |

## Часть 8. Как всё складывается в единую картину

```
[Устройство 1] ──┐
[Устройство 2] ──┼── [Коммутатор] ── [Маршрутизатор] ── [Интернет]
[Устройство 3] ──┘         │                │
                           │                │
                    коммутация по      маршрутизация
                    MAC-адресам        по IP + NAT
                    (L2)               (L3)
```

1. Устройства в ЛВС имеют **приватные IP** и общаются через **коммутатор** (по MAC).
2. Когда нужен выход в интернет — трафик идёт на **маршрутизатор**.
3. Роутер **подменяет** приватный IP на публичный (NAT) и отправляет в глобальную сеть.
4. Ответ возвращается роутеру, он **вспоминает**, кому адресован, и передаёт обратно.

**Вот и вся матрёшка: ЛВС → коммутатор → роутер → интернет.**
