# Ethernet и его «конкуренты»

## Что такое Ethernet

Ethernet — это семейство стандартов канального уровня (L2 модели OSI), описывающих проводную передачу данных между устройствами в пределах одного локального сегмента сети. Внутри него не один протокол, а целая стопка спецификаций (IEEE 802.3): общий формат кадра, правила доступа к среде (исторически CSMA/CD, сегодня — полный дуплекс без коллизий), MAC-адресация, а также физический уровень — среды и скорости от 10 Мбит/с по витой паре до 400 Гбит/с и выше по оптоволокну.

Ethernet работает только внутри одного L2-сегмента: он доставляет кадр между соседними устройствами, но не маршрутизирует между сетями (это задача IP) и не гарантирует доставку (это задача TCP и выше). Домашняя сеть — это обычно Ethernet + IP + TCP/UDP + приложения. Глобальная сеть — это IP поверх самых разных L2-технологий, где Ethernet лишь один из кирпичей.

## Прямые альтернативы на канальном уровне

**Wi-Fi (IEEE 802.11)** — главная реальная альтернатива Ethernet сегодня. Тот же L2, но среда — радиоканал, доступ через CSMA/CA. Используется везде, где нужна мобильность: дома, в офисах, кафе, аэропортах, на смартфонах и ноутбуках. Минусы — разделяемая среда, помехи, нестабильность, больший latency, вопросы безопасности.

**Token Ring (IEEE 802.5, IBM)** — кольцевая топология с маркерным доступом, коллизий нет по определению, предсказуемое время доступа. Использовалась в корпоративных сетях 1980–90-х. Проиграла Ethernet из-за цены и сложности.

**FDDI** — двойное оптоволоконное кольцо на 100 Мбит/с с отказоустойчивостью. Применялась в магистралях 1990-х, вытеснена Gigabit Ethernet.

**ARCNET** — шина или звезда с маркерным доступом, до 10 Мбит/с. Жила в промышленной автоматизации, сейчас почти не встречается.

**AppleTalk / LocalTalk** — собственный стек Apple для Mac. Вытеснен Ethernet.

**PPP / PPPoE** — канальный уровень для соединений точка-точка. Используется в dial-up и DSL, формально L2-альтернатива, но не для локальных сетей.

**HDLC, Frame Relay, ATM** — WAN-технологии канального уровня. ATM с ячейками фиксированного размера и QoS применялась в операторских сетях, вытеснена Ethernet/IP.

## Промышленные шины

**CAN / CANopen** — шинная топология, устойчивость к помехам. Автомобили и промышленность.

**Modbus RTU** — классика АСУ ТП, работает поверх RS-485.

**PROFIBUS** — экосистема Siemens в промышленности. PROFINET — уже Ethernet с реальным временем.

**LIN, FlexRay, MOST** — автомобильные шины: LIN для простой периферии, FlexRay для критичных систем, MOST для мультимедиа.

**RS-485 / RS-232 / RS-422** — последовательные интерфейсы, до сих пор живут в промышленности и телеметрии.

## Дата-центры, HPC и хранение

**InfiniBand** — реальный конкурент Ethernet в суперкомпьютерах и HPC: выше скорость, ниже latency. Используется в кластерах, где важна производительность обмена между узлами.

**Fibre Channel** — сети хранения (SAN). Вытесняется Ethernet-решениями (iSCSI, FCoE).

## Беспроводные и IoT

**Zigbee, Z-Wave, Thread** — mesh-сети для умного дома и IoT: низкое энергопотребление, низкая скорость.

**BLE (Bluetooth Low Energy)** — персональные сети, периферия, носимые устройства.

**LoRaWAN, NB-IoT, Sigfox** — LPWAN для телеметрии на километры: счётчики, датчики, сельское хозяйство, логистика.

**5G / LTE** — мобильный доступ, в том числе фиксированный (FWA) — прямая замена «последней мили».

## Магистрали и глобальные сети

**SONET/SDH** — оптические кольца операторов связи, вытесняются OTN и Carrier Ethernet.

**MPLS** — не альтернатива Ethernet, а надстройка над ним для операторов.

**PON, DOCSIS** — технологии доступа: оптические сети до квартиры и кабельный интернет.

## Где что используется — сводка

| Область | Основное решение | Альтернативы |
|---|---|---|
| Домашний LAN | Ethernet + Wi-Fi | — |
| Офисный LAN | Ethernet + Wi-Fi | — |
| Дата-центр | Ethernet | InfiniBand |
| HPC / суперкомпьютеры | InfiniBand | Ethernet |
| Промышленность | Ethernet (PROFINET, EtherCAT) | CAN, Modbus, PROFIBUS |
| Автомобили | CAN, LIN, FlexRay | Ethernet (automotive Ethernet) |
| IoT / умный дом | Wi-Fi, Zigbee, Thread | Z-Wave, BLE, LoRaWAN |
| Сети хранения | Fibre Channel | iSCSI/FCoE поверх Ethernet |
| Последняя миля | PON, DOCSIS, 5G | LTE, FWA |
| Магистрали операторов | OTN, Carrier Ethernet | SONET/SDH |

## Как технологии комбинируют

В реальности никто не выбирает «или Ethernet, или что-то другое». Технологии **наслаиваются друг на друга**, и каждая работает на своём участке пути.

**Принцип стека.** Данные идут сверху вниз: приложение → TCP/UDP → IP → канальный уровень → физика. На каждом участке пути канальный уровень может быть свой, а IP остаётся неизменным. Именно поэтому интернет может работать поверх чего угодно — от Ethernet до спутника.

**Типичный путь пакета из дома в интернет:**

1. **Устройство → роутер** — Wi-Fi или Ethernet (витая пара).
2. **Роутер → ONT/модем** — Ethernet.
3. **ONT → провайдер** — PON (оптика до квартиры) или DOCSIS (кабельный интернет).
4. **Сеть провайдера** — Carrier Ethernet, MPLS, OTN на магистралях.
5. **Магистрали между городами и странами** — DWDM по оптоволокну, поверх — OTN, поверх — Ethernet или IP/MPLS.
6. **Дата-центр** — Ethernet внутри стойки и между стойками, InfiniBand в HPC-кластерах.
7. **Сервер** — Ethernet, иногда Fibre Channel для хранилища.

На каждом шаге пакет «переодевается» в новый канальный кадр, но IP-адресация остаётся сквозной.

**Примеры комбинирования:**

- **Ethernet поверх PON** — провайдер тянет оптику, а абоненту отдаёт обычный Ethernet-порт.
- **IP поверх MPLS поверх Ethernet** — операторская магистраль.
- **Ethernet поверх SDH/OTN** — старая оптика, по которой гоняют Ethernet.
- **Wi-Fi + Ethernet** — точка доступа подключается к коммутатору кабелем, а клиенты — по радио.
- **CAN + Ethernet** — в автомобиле шлюз (gateway) соединяет медленную шину с бортовой Ethernet-сетью.
- **LoRaWAN + Ethernet** — шлюз собирает данные с датчиков по радио и отдаёт их в сеть по кабелю.

## Протоколы «высшего порядка» у провайдеров

Да, провайдеры и операторы используют свои технологии — как на канальном, так и на сетевом уровне. Ключевое отличие: **для абонента всё выглядит как обычный интернет (IP), но внутри операторской сети работают другие протоколы.**

**На канальном и физическом уровне:**

- **PON (GPON, XGS-PON)** — пассивные оптические сети до квартиры. Одно волокно делится на десятки абонентов через сплиттеры.
- **DOCSIS** — интернет по коаксиальному кабелю (кабельные операторы).
- **DWDM** — плотное спектральное мультиплексирование: по одному волокну передают десятки и сотни длин волн, каждая — отдельный канал на терабиты.
- **OTN** — оптическая транспортная сеть, современная замена SDH.
- **SDH/SONET** — устаревшие, но ещё живые оптические кольца.
- **Carrier Ethernet** — Ethernet, адаптированный для операторских сетей: VLAN-стеки, OAM, защита, SLA.

**На сетевом уровне:**

- **MPLS** — метки вместо IP-адресов для быстрой коммутации, QoS, VPN для корпоративных клиентов.
- **BGP** — маршрутизация между автономными системами, «клей» интернета.
- **Segment Routing, SRv6** — современные подходы к управлению трафиком.
- **VXLAN, EVPN** — оверлеи для дата-центров и облаков.

**Для абонента это невидимо:** он получает IP-адрес, и весь стек выше работает стандартно. Но внутри сети провайдера пакет может проходить через MPLS-метки, OTN-контейнеры, PON-кадры — и всё это не мешает ему оставаться IP-пакетом на концах.

## Итог

Ethernet — это стандарт канального уровня для проводной локальной передачи кадров, а не «способ построить любую сеть». Он победил в локальных сетях и дата-центрах благодаря дешевизне, простоте и масштабируемости по скоростям, но не строит интернет в одиночку — поверх него работает IP, а на магистралях и в нишах живут другие технологии. Единственная массовая альтернатива Ethernet сегодня — Wi-Fi; всё остальное (InfiniBand, промышленные шины, IoT-протоколы, Fibre Channel) занимает конкретные ниши, где у Ethernet нет преимуществ или есть более подходящие решения.

При этом технологии не конкурируют «насмерть», а **наслаиваются**: Ethernet поверх PON, IP поверх MPLS, Ethernet поверх OTN, Wi-Fi поверх Ethernet. Провайдеры используют собственные протоколы (PON, DWDM, OTN, MPLS, BGP), но для абонента всё сводится к обычному IP — потому что интернет строится не на одной технологии, а на стеке, где каждый уровень решает свою задачу.
