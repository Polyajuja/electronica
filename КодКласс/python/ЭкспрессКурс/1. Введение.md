## 1.1. Почему мне стоит использовать Python?

Существуют сотни языков — от C и C++ до Ruby, C# и Java. Ни один язык не идеален для всех задач, но Python хорошо подходит для многих и удобен для обучения. Сотни тысяч программистов используют его, и их число растёт.

Python — полноценный кроссплатформенный язык: одинаково работает на Windows, Linux/UNIX и Macintosh, от суперкомпьютеров до телефонов. Подходит и для маленьких приложений, и для больших проектов. В поставку входят GUI-инструменты, библиотеки для веба и многое другое — и всё бесплатно.

## 1.2. Сильные стороны Python

> **Python** — современный высокоуровневый язык программирования с динамической типизацией, простым логичным синтаксисом и семантикой.

Создан Гвидо ван Россумом в 1990-е, назван в честь «Монти Пайтон».

### 1.2.1. Python прост в использовании

Знакомые конструкции (циклы, условия, массивы) есть, но проще:

- **Типы привязаны к объектам, а не к переменным.** Переменной можно присвоить значение любого типа, список — хранить объекты разных типов. Преобразование типов часто не нужно.
- **Высокий уровень абстракции.** Отчасти из-за устройства языка, отчасти из-за богатой стандартной библиотеки. Загрузка веб-страницы — 2–3 строки.
- **Простой синтаксис.** Новичок быстро начинает писать полезный код.

Python хорош для быстрой разработки: приложение пишется в 5 раз быстрее и занимает в 5 раз меньше строк, чем на C. Правда, для числовых алгоритмов с целочисленными циклами `for` выигрыш меньше.

### 1.2.2. Выразительность Python

> **Выразительность** — свойство языка, при котором одна строка кода делает больше, чем строка в других языках.

Чем меньше строк — тем быстрее проект и проще сопровождение.

Пример — перестановка двух переменных. В Java:

```java
int temp = var1;
var1 = var2;
var2 = temp;
```

В Python — одна строка:

```python
var2, var1 = var1, var2
```

### 1.2.3. Удобочитаемость кода

Код читают люди: при отладке, сопровождении, доработке. Чем понятнее — тем лучше. Главное преимущество Python — **обязательные отступы**: код всегда оформлен единообразно.

Сравните Perl и Python для одной задачи (парная сумма списков):

```perl
# Версия Perl.
sub pairwise_sum {
    my($arg1, $arg2) = @_;
    my @result;
    for(0 .. $#$arg1) {
        push(@result, $arg1->[$_] + $arg2->[$_]);
    }
    return(\@result);
}
```

```python
# Версия Python.
def pairwise_sum(list1, list2):
    result = []
    for i in range(len(list1)):
        result.append(list1[i] + list2[i])
    return result
```

Код Python читается легче.

### 1.2.4. «Батарейки в комплекте»

> **«Батарейки в комплекте»** — принцип поставки Python: при установке вы получаете всё необходимое, дополнительные библиотеки не нужны.

Стандартная библиотека включает модули для почты, веб-страниц, баз данных, функций ОС, GUI и т. д. Пример — веб-сервер в две строки:

```python
import http.server
http.server.test(HandlerClass=http.server.SimpleHTTPRequestHandler)
```

### 1.2.5. Кроссплатформенность

> **Кроссплатформенность** — способность языка и программ работать на разных платформах без изменения кода.

Python работает на Windows, Mac, Linux, UNIX и др. Код выполняется везде, где есть интерпретатор. Есть версии для Java (Jython) и .NET (IronPython).

### 1.2.6. Свободное распространение

Python бесплатен и разрабатывается как открытый проект. Можно скачать, использовать в коммерческих и личных целях — без оплаты.

> **Открытый исходный код** — модель разработки, при которой исходный код доступен для изучения, изменения и распространения.

Код открыт: можно изменять, улучшать, расширять. Можно вносить вклад — финансово (PSF), участием в SIG, тестированием или применением разработок. Python используют Google, Rackspace, Industrial Light & Magic, Honeywell — он надёжен и хорошо поддерживается сообществом.

Итак: выразительность, удобочитаемость, богатые библиотеки, кроссплатформенность, открытый код. В чём подвох?

## 1.3. Не самые сильные стороны Python

Ни один язык не идеален. Вот где Python слабее.

### 1.3.1. Не самый быстрый

Python не компилируемый: код сначала компилируется в байт-код, затем выполняется интерпретатором.

> **Байт-код** — промежуточное представление программы перед выполнением интерпретатором.

В некоторых областях (регулярные выражения) Python не уступает C. Но обычно он медленнее C. Впрочем, скорость разработки часто важнее скорости выполнения, а тяжёлые части можно вынести в модули на C/C++.

### 1.3.2. Не лидер по количеству библиотек

У C, Java и Perl библиотек больше. Но это касается узких задач, а Python легко расширяется — своим кодом или библиотеками на C. Для повседневных задач возможностей хватает.

### 1.3.3. Не проверяет типы во время компиляции

Переменные в Python — скорее метки для объектов, чем контейнеры. Объект имеет тип, переменная — нет:

```python
>>> x = "2"
>>> x
'2'                  # строка
>>> x = int(x)
>>> x
2                    # целое число
```

> **Динамическая типизация** — тип связан со значением, а не с переменной, и проверяется во время выполнения.

Интерпретатор не поймает несовпадение типов: присвоить целочисленной переменной строку `"two"` можно. Программисты из «строгих» языков считают это минусом, но гибкость обычно перевешивает, а тесты помогают ловить ошибки.

### 1.3.4. Слабая поддержка мобильных устройств

Смартфоны, планшеты, хромбуки — везде разные ОС. Python здесь не силён: запуск возможен, но не всегда прост, а с коммерческими приложениями возникают проблемы.

### 1.3.5. Слабая многопроцессорная поддержка

Многоядерные процессоры дают прирост, но стандартный Python ограничен механизмом GIL (Global Interpreter Lock).

> **GIL (Global Interpreter Lock)** — механизм CPython, позволяющий только одному потоку выполнять байт-код в момент времени.

Параллельные процессы возможны, но встроенная параллелизация — не сильная сторона Python. Подробности — в вики Python: https://wiki.python.org/moin/GlobalInterpreterLock.

## 1.4. Почему нужно изучать Python 3?

Книга написана на основе Python 3.6 (тестировался и 3.7). Python 3 — первая версия с нарушенной обратной совместимостью: старый код без правок может не работать. Например, `print` стал функцией:

```python
print "hello"     # Python 2
print("hello")    # Python 3
```

Изменения невелики, но делают язык последовательнее и однозначнее. Это не переработка, а продуманная эволюция. Для миграции есть инструменты и библиотеки Six и Future.

Почему Python 3? Это лучшая версия на сегодня и доминирующая на ближайшие годы. По данным http://py3readiness.org, 319 из 360 популярных библиотек уже портированы. Если нужна непортированная библиотека или есть код на Python 2 — используйте Python 2.x. Но для новых проектов и обучения — Python 3. За ним будущее.

## Итоги

- Python — современный высокоуровневый язык с динамической типизацией, простым синтаксисом и семантикой.
- Многоплатформенный, модульный, подходит и для быстрой разработки, и для крупных проектов.
- Работает достаточно быстро, расширяется модулями C/C++.
- Есть долгосрочное хранение объектов, хеш-таблицы, расширяемый синтаксис классов, универсальные функции сравнения.
- Библиотеки для числовых данных, графики, GUI и веб-сценариев.
- Поддерживается активным сообществом.

Кратко по платформам:

> **Anaconda: альтернативный дистрибутив.** Популярен среди учёных и специалистов по данным. Включает Python, язык R и множество пакетов для анализа данных, управляется менеджером conda. Есть версия miniconda — только Python и conda. Загрузка: www.anaconda.com/download/. Для Data Science — самый быстрый способ начать.

## 2.2. Базовый интерактивный режим и IDLE

Два способа работы с интерпретатором: базовый режим (командная строка) и IDLE.

> **Базовый интерактивный режим** — работа с Python через командную строку: команды вводятся в приглашении `>>>` и выполняются сразу.

IDLE удобнее, но может требовать отдельной установки. Базовый режим иногда всё равно нужен — стоит уметь пользоваться обоими.

### 2.2.1. Базовый интерактивный режим

Среда примитивна, но примеры в книге небольшие. Позже вы научитесь подключать код из файлов через модули.

Запуск:

- **Windows** — команда Python 3.6 (32-bit) из меню Пуск → Программы → Python 3.6, либо двойной щелчок на `Python.exe` (например, в `C:\Users\myuser\AppData\Local\Programs\Python\Python35-32`). Откроется окно, как на рис. 2.1.

  Рис. 2.1 — Базовый интерактивный режим в Windows 10

- **macOS** — откройте терминал и введите `python3`. Если «Команда не найдена» — запустите Update Shell Profile из папки Python3 в Applications.
- **UNIX** — введите `python3`. Появится сообщение с версией и приглашение `>>>`.

> **Выход из сеанса:** Ctrl+Z (Windows), Ctrl+D (Linux/UNIX) или `exit()`.

Поддерживается история команд: стрелки ↑/↓, Home, End, Page Up/Down; Enter повторяет команду. Этого достаточно для примеров книги. Альтернатива — режим Python для Emacs.

### 2.2.2. Интегрированная среда разработки IDLE

IDLE = «integrated development environment» (название также намекает на Эрика Айдла из «Монти Пайтон»). Объединяет интерпретатор, редактор и отладчик — хорошая отправная точка для изучения Python.

Запуск:

- **Windows** — IDLE в подменю Python 3.6 из папки Все приложения. Окно — как на рис. 2.2.

  Рис. 2.2 — IDLE в Windows

- **macOS** — папка Python 3.x в Applications → запустите IDLE.
- **Linux/UNIX** — команда `idle3`. Либо через подменю Programming менеджера пакетов.

### 2.2.3. Выбор между базовым режимом и IDLE

На первых порах используйте IDLE или окно оболочки Python — их хватит до главы 10. Дальше понадобится создание модулей, и IDLE даст удобные средства для работы с файлами. Если есть любимый редактор — можно обойтись базовым режимом и им. Нет предпочтений — берите IDLE.

## 2.3. Использование окна оболочки Python в IDLE

При запуске IDLE открывается окно оболочки (рис. 2.3). IDLE автоматически расставляет отступы и подсвечивает синтаксис.

Навигация — мышь, клавиши курсора, Page Up/Down, привязки Emacs (см. меню Help).

Сеанс буферизуется: можно прокручивать и искать. Курсор в строке + Enter — строка копируется вниз для редактирования и повторного выполнения. В нижнем поле Alt+P / Alt+N перебирают историю команд. Tab — автодополнение ключевых слов и имён.

Если программа «зависла» и не выводит приглашение — интерпретатор ждёт ввода. Ctrl+C прерывает программу. Выход из IDLE — File → Exit.

Чаще всего пригодится меню Edit; его можно отсоединить двойным щелчком по пунктирной линии.

## 2.4. Hello, World

В интерактивном режиме вы увидите приглашение `>>>`. Вводите команду и нажимайте Enter. Классическая первая программа:

```python
>>> print("Hello, World")
Hello, World
```

Функция `print` выводит аргумент в стандартный вывод (обычно на экран). Тот же результат был бы при выполнении из файла.

Поздравляю — вы написали первую программу на Python!

## 2.5. Использование интерактивного приглашения для изучения Python

Полезные инструменты:

- **`help()`** — справка. Без аргументов — справочный режим с приглашением `help>`; с аргументом — документация по объекту:

```python
>>> x = 2
>>> help(x)
Help on int object:
```

# FAQ

**Нужно ли читать главу 1, чтобы программировать на Python?**
Нет. Она даёт общую картину, но для практики можно сразу перейти к главе 3.

**Python 2 или Python 3?**
Для обучения и новых проектов — Python 3. Python 2 — только если нужна непортированная библиотека или есть готовая кодовая база на нём.

**Конфликтуют ли Python 2 и Python 3 на одном компьютере?**
Нет. В UNIX-системах они ставятся параллельно, в Windows — в разные каталоги.

**Чем IDLE отличается от базового режима?**
IDLE — среда разработки с редактором, подсветкой синтаксиса и отладчиком. Базовый режим — просто командная строка с интерпретатором.

**Почему Python медленнее C?**
Он интерпретируемый: код компилируется в байт-код и выполняется интерпретатором, а не напрямую процессором. Тяжёлые части можно вынести в модули на C/C++.

**Что такое GIL и мешает ли он?**
Global Interpreter Lock позволяет выполняться только одному потоку байт-кода за раз. Это ограничивает параллелизм на многоядерных процессорах.

**Зачем нужны `help()` и `dir()`?**
`help()` выводит документацию по объекту, `dir()` — список объектов в пространстве имён. Оба помогают изучать Python и отлаживать код.

**Как выйти из интерактивного сеанса?**
Ctrl+Z (Windows), Ctrl+D (Linux/UNIX) или команда `exit()`.
