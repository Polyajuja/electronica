# 1

JavaScript объекты — это основная структура данных, используемая для хранения коллекций значений и более сложных сущностей. Объект представляет собой набор пар «ключ: значение» (свойств).

- **Ключ (key)** — это «имя» или «метка» свойства. По нему мы находим значение.
- **Значение (value)** — это то, что хранится под этим ключом. Может быть чем угодно: числом, строкой, массивом, функцией, другим объектом.

# 2

**Коллекции в JS:**
- `Array` — упорядоченный список
- `Object` — пары ключ-значение (не настоящая коллекция, но используется как словарь)
- `Map` — коллекция ключ-значение (ключи любого типа, порядок вставки)
- `Set` — множество уникальных значений
- `WeakMap` / `WeakSet` — слабые коллекции (ключи-объекты, сборка мусора)
- `TypedArray` (`Int32Array` и др.) — типизированные массивы чисел
- `ArrayBuffer` / `DataView` — бинарные данные
- Итераторы/генераторы — не коллекции, но дают перебор

# 3

## `alert(message)`
Показывает модальное окно с сообщением и кнопкой «ОК». Возвращает `undefined`. Блокирует выполнение скрипта, пока пользователь не закроет окно.

```javascript
alert("Привет!");
```

## `prompt(message, default)`
Показывает окно с полем ввода, кнопками «ОК» и «Отмена».
- Возвращает **строку** с введённым текстом при «ОК».
- Возвращает **`null`** при «Отмена» или закрытии окна.
- Второй аргумент (необязательный) — значение по умолчанию в поле ввода.

```javascript
let name = prompt("Как вас зовут?", "Гость");
if (name !== null) {
  alert("Здравствуйте, " + name);
}
```

## Важные особенности
1. **Оба блокируют поток** — код после вызова не выполнится, пока окно открыто.
2. **Возвращают примитивы**: `alert` → `undefined`, `prompt` → `string | null`. Введённое число нужно преобразовывать: `Number(prompt(...))` или `parseInt(...)`.
3. **Стиль окна** зависит от браузера, кастомизировать нельзя.
4. **Не рекомендуются** для продакшена (плохой UX, некоторые браузеры/расширения их блокируют). Для реальных проектов используют кастомные модальные окна.
5. `prompt` и `alert` — методы объекта `window`, поэтому можно писать `window.alert(...)`.
