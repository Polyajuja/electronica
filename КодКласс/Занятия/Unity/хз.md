Основные элементы UI в Unity (система **UGUI**) — это набор компонентов, которые используются для создания интерфейсов: меню, HUD, кнопок, полос здоровья и т.д.

**Canvas** — корневой контейнер, внутри которого размещаются и отрисовываются все UI-элементы.

**Text (TextMeshPro)** — компонент для отображения текста.

**Image** — компонент для отображения спрайта (иконки, фоны, рамки).

**Raw Image** — компонент для отображения текстуры (не спрайта), например Render Texture или видео.


**Button** — интерактивный элемент, реагирующий на клик и вызывающий события.

**Toggle** — переключатель с двумя состояниями (вкл/выкл), используется как чекбокс или радиокнопка.

**Slider** — ползунок для выбора значения из диапазона.

**Input Field (TMP_InputField)** — поле для ввода текста пользователем.

**Panel** — объект с компонентом Image, используемый как фон или контейнер для группировки других элементов.

Collider (коллайдер) — компонент, который задаёт форму объекта для физического взаимодействия. Именно коллайдеры, а не меши, участвуют в столкновениях и пересечениях.

Основные свойства
Is Trigger — если включено, коллайдер не вызывает физического отталкивания, а только события пересечения (OnTriggerEnter/Stay/Exit). Используется для зон (триггеров), подбора предметов, областей урона.
