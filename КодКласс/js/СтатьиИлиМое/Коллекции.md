# Коллекции в JavaScript: полный обзор

## 1. Общая картина

В JavaScript есть **два поколения** коллекций:

| Поколение | Типы | Особенности |
|-----------|------|-------------|
| **Старые** (ES1) | `Array`, `Object` | Гибкие, но с оговорками |
| **Новые** (ES6+) | `Map`, `Set`, `WeakMap`, `WeakSet` | Специализированные, предсказуемые |

```
Коллекции JS
│
├── Индексированные
│   ├── Array          — упорядоченный список
│   └── TypedArray     — типизированные массивы (Int8Array и др.)
│
├── Ключ-значение
│   ├── Object         — «старая» карта (ключи — строки/символы)
│   ├── Map            — «новая» карта (ключи — любого типа)
│   └── WeakMap        — карта со слабыми ссылками на ключи
│
└── Множества
    ├── Set            — уникальные значения
    └── WeakSet        — множество со слабыми ссылками
```

## 2. Array — упорядоченный список

### Создание
```javascript
const a1 = [1, 2, 3];
const a2 = new Array(3);        // [ <3 empty items> ]
const a3 = new Array(1, 2, 3);  // [1, 2, 3]
const a4 = Array.from("abc");   // ["a", "b", "c"]
const a5 = Array.of(1, 2, 3);   // [1, 2, 3]
```

### Ключевые свойства
```javascript
const arr = [1, 2, 3];
arr.length;          // 3
arr[0];              // 1
arr[-1];             // undefined (нет отрицательных индексов!)
arr[10] = 99;        // разряжённый массив, length = 11
```

### Основные методы

**Мутирующие (меняют массив):**
```javascript
arr.push(4);           // добавить в конец
arr.pop();             // убрать с конца
arr.unshift(0);        // добавить в начало
arr.shift();           // убрать из начала
arr.splice(1, 2);      // удалить/вставить в середине
arr.sort();            // сортировка (по строковому представлению!)
arr.reverse();         // развернуть
arr.fill(0);           // заполнить
```

**Не мутирующие (возвращают новый массив):**
```javascript
arr.slice(1, 3);       // подмассив
arr.concat([4, 5]);    // склеить
arr.map(x => x * 2);   // преобразовать
arr.filter(x => x > 1); // отфильтровать
arr.flat();            // развернуть вложенные
arr.flatMap(x => [x, x]); // map + flat
arr.toSorted();        // сортировка (ES2023)
arr.toReversed();      // разворот (ES2023)
arr.toSpliced(1, 2);   // splice (ES2023)
arr.with(1, 99);       // замена по индексу (ES2023)
```

**Поиск:**
```javascript
arr.indexOf(2);        // индекс или -1
arr.lastIndexOf(2);
arr.includes(2);       // true/false
arr.find(x => x > 1);  // первый подходящий
arr.findIndex(x => x > 1);
arr.findLast(x => x > 1);      // ES2023
arr.findLastIndex(x => x > 1); // ES2023
```

**Итерация:**
```javascript
arr.forEach(x => console.log(x));
arr.some(x => x > 2);   // хотя бы один
arr.every(x => x > 0);  // все
arr.reduce((acc, x) => acc + x, 0);
arr.reduceRight((acc, x) => acc + x, 0);
```

**Итераторы:**
```javascript
for (const x of arr) { }              // значения
for (const [i, x] of arr.entries()) { } // индексы + значения
for (const i of arr.keys()) { }       // индексы
for (const x of arr.values()) { }     // значения
```

### Особенности
- **Массив — это объект** с числовыми ключами и `length`.
- `length` — не количество элементов, а **последний индекс + 1**.
- `delete arr[0]` оставляет «дырку» (`<1 empty item>`).
- `sort()` по умолчанию **сортирует как строки**: `[10, 2, 1].sort()` → `[1, 10, 2]`.
- Для чисел: `arr.sort((a, b) => a - b)`.

## 3. Object — «старая» карта

```javascript
const obj = { a: 1, b: 2 };
```

### Ограничения ключей
- Ключи — **только строки или символы**.
- Числовые ключи автоматически преобразуются в строки: `obj[1]` = `obj["1"]`.
- Объекты как ключи → `"[object Object]"` — коллизии!

```javascript
const o = {};
const k1 = { id: 1 };
const k2 = { id: 2 };
o[k1] = "a";
o[k2] = "b";
console.log(o);  // { "[object Object]": "b" } — k1 перезаписан!
```

### Методы
```javascript
Object.keys(obj);    // ["a", "b"]
Object.values(obj);  // [1, 2]
Object.entries(obj); // [["a", 1], ["b", 2]]
Object.assign({}, obj); // поверхностная копия
Object.freeze(obj);  // запретить изменения
Object.fromEntries([["a", 1]]); // { a: 1 }
```

### Когда использовать Object вместо Map
- Простые структуры с фиксированным набором строковых ключей.
- Когда нужна сериализация в JSON (`Map` не сериализуется напрямую).
- Когда важна производительность для маленьких объектов.

## 4. Map — «новая» карта

```javascript
const map = new Map();
map.set("key", "value");
map.set(42, "число");
map.set({ id: 1 }, "объект");  // ключ — объект!

map.get("key");        // "value"
map.has(42);           // true
map.delete(42);        // удалить
map.size;              // размер
map.clear();           // очистить
```

### Ключевые отличия от Object

| | `Object` | `Map` |
|--|----------|-------|
| Ключи | строки/символы | **любой тип** |
| Порядок | не гарантирован до ES2015 | **порядок вставки** |
| Размер | `Object.keys(o).length` | `map.size` |
| Итерация | через `for...in` (с оговорками) | `for...of` напрямую |
| Производительность | медленнее для частых добавлений/удалений | быстрее |
| JSON | `JSON.stringify(o)` | не сериализуется |
| Прототип | есть (риск коллизий) | нет (чистая карта) |

### Итерация
```javascript
for (const [k, v] of map) { }        // ключ + значение
for (const k of map.keys()) { }
for (const v of map.values()) { }
for (const [k, v] of map.entries()) { }
map.forEach((v, k) => { });
```

### Преобразования
```javascript
// Object → Map
const map = new Map(Object.entries({ a: 1, b: 2 }));

// Map → Object
const obj = Object.fromEntries(map);

// Map → Array
const arr = [...map];  // [[k, v], ...]
```

## 5. WeakMap — карта со слабыми ссылками

```javascript
const wm = new WeakMap();
let key = { id: 1 };
wm.set(key, "value");
wm.get(key);  // "value"
```

### Особенности
- **Ключи — только объекты** (не примитивы).
- **Слабые ссылки**: если на ключ больше нет ссылок, запись удаляется сборщиком мусора.
- **Не итерируется** — нет `size`, `keys()`, `values()`, `forEach()`.
- **Только** `get`, `set`, `has`, `delete`.

### Зачем нужен
- Приватные данные, привязанные к объекту.
- Кэширование без утечек памяти.
- Метаданные для DOM-элементов.

```javascript
const cache = new WeakMap();

function process(obj) {
    if (cache.has(obj)) return cache.get(obj);
    const result = expensiveCalculation(obj);
    cache.set(obj, result);
    return result;
}
// Когда obj удаляется из DOM — запись автоматически исчезает
```

## 6. Set — множество уникальных значений

```javascript
const set = new Set([1, 2, 3, 2, 1]);
console.log(set);  // Set(3) { 1, 2, 3 }
```

### Методы
```javascript
set.add(4);
set.has(2);        // true
set.delete(2);
set.size;          // 3
set.clear();
```

### Итерация
```javascript
for (const v of set) { }
set.forEach(v => { });
```

### Операции над множествами (ES2025)
```javascript
const a = new Set([1, 2, 3]);
const b = new Set([2, 3, 4]);

a.union(b);              // {1, 2, 3, 4}
a.intersection(b);       // {2, 3}
a.difference(b);         // {1}
a.symmetricDifference(b); // {1, 4}
a.isSubsetOf(b);         // false
a.isSupersetOf(b);       // false
a.isDisjointFrom(b);     // false
```

> В старых версиях эти операции приходилось писать вручную — см. ниже.

### Классические операции вручную
```javascript
// Объединение
new Set([...a, ...b]);

// Пересечение
new Set([...a].filter(x => b.has(x)));

// Разность
new Set([...a].filter(x => !b.has(x)));
```

### Особенности
- **Уникальность** определяется через `SameValueZero` (как `===`, но `NaN === NaN`).
- Порядок — **порядок вставки**.
- `-0` и `+0` считаются одинаковыми.
- Объекты сравниваются **по ссылке**: `new Set([{}, {}])` → 2 элемента.

### Типичные применения
```javascript
// Удаление дубликатов
const unique = [...new Set([1, 2, 2, 3, 3])];  // [1, 2, 3]

// Проверка принадлежности
const allowed = new Set(["admin", "user"]);
allowed.has("admin");  // true
```

## 7. WeakSet — множество со слабыми ссылками

```javascript
const ws = new WeakSet();
let obj = {};
ws.add(obj);
ws.has(obj);     // true
ws.delete(obj);
```

### Особенности
- **Только объекты** как элементы.
- **Слабые ссылки** — сборщик мусора может удалить.
- **Не итерируется**, нет `size`.
- Только `add`, `has`, `delete`.

### Применение
```javascript
// Отметка обработанных объектов
const processed = new WeakSet();

function process(obj) {
    if (processed.has(obj)) return;
    // ... обработка
    processed.add(obj);
}
```

## 8. TypedArray — типизированные массивы

Для работы с бинарными данными и производительности:

```javascript
const i8  = new Int8Array(4);      // -128..127
const u8  = new Uint8Array(4);     // 0..255
const i16 = new Int16Array(4);
const i32 = new Int32Array(4);
const f32 = new Float32Array(4);
const f64 = new Float64Array(4);
const b   = new BigInt64Array(4);
```

### Особенности
- Фиксированный размер, фиксированный тип.
- **Не наследуют** методы `Array` (`map`, `filter` есть, `push` — нет).
- Работают с `ArrayBuffer` — сырой памятью.

```javascript
const buffer = new ArrayBuffer(16);
const view = new Int32Array(buffer);
view[0] = 42;
view[1] = 99;
console.log(view);  // Int32Array(4) [42, 99, 0, 0]
```

### Применение
- WebGL, WebAssembly, аудио/видео, сетевые протоколы.

## 9. Сравнительная таблица

| Коллекция | Ключи | Уникальность | Порядок | Итерация | Слабые ссылки |
|-----------|-------|--------------|---------|----------|---------------|
| `Array` | индексы | нет | да | `for...of` | нет |
| `Object` | строки/символы | ключи | да (ES2015+) | `for...in` | нет |
| `Map` | любой тип | ключи | да | `for...of` | нет |
| `WeakMap` | объекты | ключи | нет | ❌ | ✅ |
| `Set` | — | значения | да | `for...of` | нет |
| `WeakSet` | — | значения | нет | ❌ | ✅ |
| `TypedArray` | индексы | нет | да | `for...of` | нет |

## 10. Что когда использовать

| Задача | Инструмент |
|--------|-----------|
| Упорядоченный список | `Array` |
| Удаление дубликатов | `Set` |
| Проверка принадлежности (быстро) | `Set` |
| Ключ-значение с любыми ключами | `Map` |
| Ключ-значение со строковыми ключами | `Object` |
| Приватные данные объекта | `WeakMap` |
| Кэш без утечек | `WeakMap` |
| Отметка обработанных объектов | `WeakSet` |
| Бинарные данные / производительность | `TypedArray` |
| Очередь / стек | `Array` (`push`/`shift`, `push`/`pop`) |
| Очередь с обоих концов | `Array` или самодельный `Deque` |

## 11. Пример: комплексное использование

```javascript
"use strict";

// Задача: подсчитать частоту слов и найти уникальные

const text = "the quick brown fox jumps over the lazy dog the fox";
const words = text.split(" ");

// Map для частот
const freq = new Map();
for (const w of words) {
    freq.set(w, (freq.get(w) ?? 0) + 1);
}
console.log(freq);
// Map(8) { 'the' => 3, 'quick' => 1, ..., 'fox' => 2 }

// Set для уникальных
const unique = new Set(words);
console.log(unique.size);  // 8

// Сортировка по частоте
const sorted = [...freq].sort((a, b) => b[1] - a[1]);
console.log(sorted);
// [['the', 3], ['fox', 2], ['quick', 1], ...]

// WeakMap для метаданных
const wordMeta = new WeakMap();
const wordObj = { text: "the" };
wordMeta.set(wordObj, { length: 3, frequency: 3 });
console.log(wordMeta.get(wordObj));  // { length: 3, frequency: 3 }
```

## 12. Итог

- **`Array`** — универсальный упорядоченный список; богатый API, но `sort()` по умолчанию строковый.
- **`Object`** — простая карта, но ключи только строки/символы, есть риск коллизий с прототипом.
- **`Map`** — современная карта: любые ключи, порядок вставки, `size`, прямая итерация.
- **`Set`** — уникальные значения, быстрая проверка принадлежности, теоретико-множественные операции.
- **`WeakMap` / `WeakSet`** — слабые ссылки, без итерации, для кэшей и приватных данных.
- **`TypedArray`** — бинарные данные и производительность.

**Правило выбора:**
- Нужны ключи-объекты или порядок вставки → `Map`.
- Нужна уникальность или быстрая проверка `has` → `Set`.
- Нужна автоматическая очистка памяти → `WeakMap` / `WeakSet`.
- Нужен JSON или простые строковые ключи → `Object`.
- Нужен упорядоченный список с индексами → `Array`.
