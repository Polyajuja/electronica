## Краткая выжимка: Логические операторы JavaScript (Глава 4)

### Операторы if и if else
Условное выполнение кода. Синтаксис:
```javascript
if (expression) {
  // выполняется, если expression === true
} else {
  // выполняется, если expression === false (необязательно)
}
```
- Выражение в скобках преобразуется к логическому значению.
- Выполняется **только один** из блоков.
- Если нет `else`, а условие ложно — программа идёт дальше.

**Типичная ошибка:** <mark>`if (hobby = "coding")` вместо `if (hobby === "coding")` — присваивание вместо сравнения. Присваивание всегда даёт непустую строку → `true`.</mark>

### Операторы else if
Цепочка проверок — <mark>выполняется **первый истинный** блок, остальные игнорируются:</mark>
```javascript
if (age < 3) {
  // ...
} else if (age < 12) {
  // ...
} else if (age < 65) {
  // ...
} else {
  // ...
}
```
- <mark>Код читается сверху вниз; как только условие истинно — остальные пропускаются.</mark>
- <mark>Если предыдущие условия исключают диапазоны, можно упрощать проверки (например, `age < 12` вместо `age >= 3 && age < 12`).</mark>

### Тернарный оператор
<mark>Сокращённая форма `if else` для простых случаев. Три операнда:</mark>
```javascript
expression ? valueIfTrue : valueIfFalse;
```
Примеры:
```javascript
let access = age < 18 ? "denied" : "allowed";
age < 18 ? console.log("denied") : console.log("allowed");
```
- Читается как: «если `expression`, тогда `valueIfTrue`, иначе `valueIfFalse`».
- Использовать только для коротких действий; для сложной логики — обычный `if else`.

### Операторы switch
Альтернатива длинным цепочкам `if else` при сравнении одного выражения с множеством значений:
```javascript
switch (expression) {
  case value1:
    // код
    break;
  case value2:
    // код
    break;
  default:
    // код, если совпадений нет
    break;
}
```
- **Строгое сравнение** (`===`) — учитываются значение и тип.
- <mark>**`break`** обязателен: без него выполнение «проваливается» в следующий case до конца switch или до `break`.</mark>
- <mark>**`default`** — аналог `else`, обычно ставится последним (но может быть где угодно).</mark>

**Объединение случаев** — <mark>несколько `case` подряд для одного действия:</mark>
```javascript
switch (grade) {
  case "F":
  case "D":
    console.log("You've failed!");
    break;
  case "C":
  case "B":
    console.log("You've passed!");
    break;
  case "A":
    console.log("Nice!");
    break;
  default:
    console.log("I don't know this grade.");
}
```
Это читабельнее, чем `if (grade === "F" || grade === "D")`.

### Сравнение if else и switch
| | if else | switch |
|---|---|---|
| Проверка | Любые логические выражения | Строгое равенство значению |
| Читаемость | Хороша для сложных условий | Лучше при 4+ вариантах одного выражения |
| Объединение | Через `\|\|` | Несколько `case` подряд |
| По умолчанию | `else` | `default` |

### Практические задания (примеры)
- Определение цены билета по возрасту.
- Проверка возраста для входа в заведение.
- Магический шар судьбы (случайный ответ через `switch`).
- Игра «Камень — ножницы — бумага».

### Итог
- `if else` — базовая конструкция ветвления.
- `else if` — множественные проверки, выполняется первый истинный блок.
- Тернарный оператор — краткая форма для простых условий.
- `switch` — удобен для сравнения одного выражения с несколькими значениями; требует `break` и поддерживает `default` и объединение `case`.

# Логические операторы

До этого момента код был статичным: при каждом вызове он выполнялся одинаково. В этой главе ситуация меняется — рассматриваются логические операторы, которые позволяют прописывать в коде различные варианты развития событий. В зависимости от результата вычисления выражения будет выполняться та или иная ветвь кода.

> Логический оператор — <mark>конструкция языка программирования, которая управляет порядком выполнения блоков кода в зависимости от истинности или ложности заданного условия.</mark>

В главе рассматриваются следующие темы:

- операторы `if` и `if else`;
- операторы `else if`;
- условные тернарные операторы;
- операторы `switch`.

Решения упражнений и проектов, а также ответы на вопросы для самопроверки находятся в приложении.

## Операторы `if` и `if else`

Принимать решения в коде позволяют операторы `if` и `if else`. Логика действий похожа на следующий шаблон:

> если (`if`) некоторые условия выполнены (`true`), тогда (`then`) выполняется определённое действие, иначе (`else`) выполняется другое действие.

> Условие — выражение, которое приводится к логическому значению (`true` или `false`) и определяет, какой блок кода будет выполнен.

> Блок кода — последовательность инструкций, заключённая в фигурные скобки `{}` и выполняемая как единое целое.

Например, если на улице идёт дождь, я возьму зонт, иначе не буду брать его с собой. Код не сильно отличается от этой формулировки:

```javascript
let rain = true;
if (rain) {
  console.log("** нужно взять зонт, когда я пойду на улицу **");
} else {
  console.log("** я могу оставить зонт дома **");
}
```

В этом случае значением `rain` является `true`. Код выведет на экран:

```
** нужно взять зонт, когда я пойду на улицу **
```

Разберём синтаксис. Мы начинаем со слова `if`. После него в скобках указывается значение. То, что находится между скобками, преобразуется в логическое значение. Если это значение `true`, выполняется блок кода, связанный с оператором `if`. Этот блок легко распознать по фигурным скобкам.

Следующая часть необязательна — это блок `else`. Он начинается словом `else` и выполняется только в том случае, если логическая переменная получает значение `false`. Если блока `else` нет, а условие ложно, программа просто перейдёт к коду ниже оператора `if`.

Таким образом, будет выполнен только один из двух блоков: блок `if`, если выражение истинно, или блок `else`, если выражение ложно:

```javascript
if (expression) {
  // код, связанный с блоком if,
  // будет выполнен, только если выражение верно
} else {
  // код, связанный с блоком else,
  // не обязательный, добавляется при необходимости
  // и будет выполнен, только если выражение ложно
}
```

Ещё один пример. Если пользователю меньше 18 лет, на экран выводится сообщение об отказе в доступе; в противном случае появляется сообщение о разрешении доступа:

```javascript
if (age < 18) {
  console.log("We're very sorry, but you can't get in under 18");
} else {
  console.log("Welcome!");
}
```

Существует распространённая ошибка кодирования, связанная с операторами `if`. Она допущена в следующем фрагменте кода. Попробуйте понять, что он делает:

```javascript
let hobby = "dancing";
if (hobby = "coding") {
  console.log("** I love coding too! **");
} else {
  console.log("** Can you teach me that? **");
}
```

В консоли отобразится:

```
** I love coding too! **
```

Возможно, это удивляет. Проблема в операторе `if`: там не хватает одного знака равно. Вместо оценки состояния он присваивает элементу `hobby` значение `coding`. Затем `coding` преобразуется в логическое значение, а поскольку это не пустая строка, значение становится истинным, поэтому блок `if` выполняется. Всегда помните: в условии следует использовать двойной знак равенства (`===`).

## Операторы `else if`

Разновидностью оператора `if` является оператор `if` со множеством блоков `else if`. Их применение в определённых ситуациях может быть более эффективным, потому что в этом случае всегда будет требоваться выполнение только одного или ни одного из блоков.

Шаблонная логика действий:

> если (`if`) значение попадает в определённую категорию, то (`then`) произойдёт определённое действие, иначе, если (`else if`) значение попадает в категорию, отличную от предыдущей инструкции, тогда (`then`) произойдёт определённое действие, иначе, если (`else if`) значение попадает в категорию, отличную от любой из предыдущих, тогда (`then`) произойдёт определённое действие.

Возьмём этот шаблон, чтобы определить, какой должна быть цена билета. Если человек младше 3 лет, вход бесплатный; иначе, если человек старше 3 лет и младше 12 лет, вход стоит 5 долларов; иначе, если человек старше 12 лет и моложе 65 лет, вход стоит 10 долларов; иначе, если человеку 65 лет и больше, вход стоит 7 долларов:

```javascript
let age = 10;
let cost = 0;
let message;
if (age < 3) {
  cost = 0;
  message = "Access is free under three.";
} else if (age >= 3 && age < 12) {
  cost = 5;
  message = "With the child discount, the fee is 5 dollars";
} else if (age >= 12 && age < 65) {
  cost = 10;
  message = "A regular ticket costs 10 dollars.";
} else {
  cost = 7;
  message = "A ticket is 7 dollars.";
}
console.log(message);
console.log("Your Total cost " + cost);
```

Скорее всего, код читается гораздо легче, чем шаблон. Это здорово! Вы уже начинаете мыслить как разработчики JavaScript.

Код выполняется сверху вниз, и будет выполнен только один из блоков. Как только встретится истинное выражение, остальные будут проигнорированы. Вот почему шаблон можно оформить следующим образом:

```javascript
if (age < 3) {
  console.log("Access is free under three.");
} else if (age < 12) {
  console.log("With the child discount, the fee is 5 dollars");
} else if (age < 65) {
  console.log("A regular ticket costs 10 dollars.");
} else if (age >= 65) {
  console.log("A ticket is 7 dollars.");
}
```

## Условные тернарные операторы

В главе 2 этот оператор был пропущен и отложен до текущего раздела. В первую очередь потому, что он помогает понять оператор `if else`. Унарный оператор называется унарным, потому что у него только один операнд. Тернарный (троичный) оператор носит своё название потому, что состоит из трёх операндов.

> Тернарный оператор — оператор, состоящий из трёх операндов и возвращающий одно из двух значений в зависимости от истинности условия.

> Операнд — величина или выражение, над которым выполняется операция.

Например:

```
операнд1 ? операнд2 : операнд3;
```

`операнд1` — это выражение, которое должно быть оценено. Если выражению будет присвоено значение `true`, будет исполнен `операнд2`. Если `false` — то `операнд3`. Знак вопроса можно прочитать как `then`, а двоеточие — как `else`:

```
выражение ? оператор в случае true : оператор в случае false;
```

Шаблонное утверждение:

> если (`if`) операнд1, тогда (`then`) операнд2, иначе (`else`) операнд3.

Рассмотрим несколько примеров:

```javascript
let access = age < 18 ? "denied" : "allowed";
```

Этот небольшой фрагмент кода присвоит значение переменной доступа `access`. Если (`if`) возраст ниже 18, тогда (`then`) запретить доступ — `denied`, иначе (`else`) разрешить — `allowed`. Также можно указать действие в тернарном операторе, например:

```javascript
age < 18 ? console.log("denied") : console.log("allowed");
```

Поначалу подобный синтаксис может сбить с толку. В этом случае шаблон логики, которую нужно воспроизвести в голове, действительно будет полезен. Тернарные операторы можно использовать только для очень коротких действий. В приведённых выше примерах они действительно облегчают чтение кода. Однако, если логика содержит несколько аргументов сравнения, придётся использовать обычную схему `if else`.

## Операторы `switch`

Операторы `if else` отлично подходят для оценки логических условий. Есть много решений, которые можно реализовать с их помощью, но в некоторых случаях лучше заменить `if else` оператором `switch`. Это особенно актуально при оценке более четырёх или пяти значений.

> Оператор `switch` — конструкция языка программирования, которая сравнивает одно выражение с несколькими возможными значениями (случаями) и выполняет код, соответствующий первому совпадению.

Рассмотрим, чем операторы `switch` могут помочь и как они выглядят. Сначала взгляните на оператор `if else`:

```javascript
if (activity === "Get up") {
  console.log("It is 6:30AM");
} else if (activity === "Breakfast") {
  console.log("It is 7:00AM");
} else if (activity === "Drive to work") {
  console.log("It is 8:00AM");
} else if (activity === "Lunch") {
  console.log("It is 12.00PM");
} else if (activity === "Drive home") {
  console.log("It is 5:00PM");
} else if (activity === "Dinner") {
  console.log("It is 6:30PM");
}
```

Данный код на основании ваших действий определяет текущее время суток. Но лучше было бы реализовать его с помощью оператора `switch`. Синтаксис оператора `switch` выглядит так:

```javascript
switch (expression) {
  case value1:
    // исполняемый код
    break;
  case value2:
    // исполняемый код
    break;
  case valueN:
    // исполняемый код
    break;
}
```

Это можно прочитать следующим образом:

> если выражение равно `value1`, выполните код, указанный для этого случая. Если выражение равно `value2`, выполните код, указанный для этого случая, и т. д.

Вот как можно переписать длинный код с `if else` гораздо более чистым способом, используя оператор `switch`:

```javascript
switch (activity) {
  case "Get up":
    console.log("It is 6:30AM");
    break;
  case "Breakfast":
    console.log("It is 7:00AM");
    break;
  case "Drive to work":
    console.log("It is 8:00AM");
    break;
  case "Lunch":
    console.log("It is 12:00PM");
    break;
  case "Drive home":
    console.log("It is 5:00PM");
    break;
  case "Dinner":
    console.log("It is 6:30PM");
    break;
}
```

Если значение того, чем мы сейчас занимаемся, равняется `Lunch`, программа выведет на экран:

```
It is 12:00PM
```

Возможно, интересно, что это за `break` в конце блоков и зачем он нужен. Если не написать `break`, код выполнит следующий блок тоже. Так будет происходить с момента совпадения и до конца блока `switch` — или до тех пор, пока мы не столкнёмся с оператором `break`. Вот каким был бы результат работы оператора `switch` без операторов `break` при вводе значения `Lunch`:

```
It is 12:00PM
It is 5:00PM
It is 6:30PM
```

> Оператор `break` — инструкция, которая прерывает выполнение текущего блока `switch` или цикла и передаёт управление коду, следующему за ним.

Одно последнее замечание. Оператор `switch` использует строгую проверку типов (стратегия тройного равенства `===`) для определения равенства, проверяя как значения, так и тип данных.

### Случай по умолчанию

Есть одна часть `switch`, с которой мы ещё не работали, — это метка случая по умолчанию, называемая `default`. Она очень похожа на часть `else` оператора `if else`. Если `switch` не находит совпадения ни с одним из случаев, но видит код, который предлагается выполнить по умолчанию, он выполнит именно его. Вот шаблон инструкции `switch` с вариантом по умолчанию:

```javascript
switch (expression) {
  case value1:
    // исполняемый код
    break;
  case value2:
    // исполняемый код
    break;
  case valueN:
    // исполняемый код
    break;
  default:
    // исполняемый код, если совпадения не найдены
    break;
}
```

> Метка `default` — необязательный блок в операторе `switch`, который выполняется, если ни один из случаев `case` не совпал с выражением.

Общепринято использовать оператор `default` в качестве последнего варианта в инструкции `switch`, но код будет работать без сбоев, даже если блок `default` расположен в середине или в начале. Всё же рекомендуется придерживаться привычной для всех последовательности, поскольку именно этого будут ожидать другие разработчики (и, возможно, вы сами в будущем) при работе с уже написанным кодом.

Допустим, с нашим длинным условием `if` связан оператор `else`, который выглядит следующим образом:

```javascript
if (…) {
  // опустим, чтобы не делать код излишне длинным
} else {
  console.log("I cannot determine the current time.");
}
```

### Практическое занятие 4.4

Как уже говорилось в главе 1, JavaScript-функция `Math.random()` вернёт случайное числовое значение в диапазоне от 0 до 1, включая 0 и исключая 1. Затем его можно масштабировать до нужного диапазона, умножив результат и используя `Math.floor()`, чтобы округлить его до ближайшего целого числа; например, для генерации случайного числа от 0 до 9:

```javascript

randomNumber = randomNumber * 10;
// удаляем значки после десятичной запятой, чтобы получить целое число
randomNumber = Math.floor(randomNumber);
```

### Сочетание операторов

Иногда может понадобиться совершить одно и то же действие в нескольких разных случаях. В операторе `if` придётся для этого указать все возможные варианты «ИЛИ» (`||`). В инструкции `switch` можно просто объединить случаи, написав их друг за другом следующим образом:

```javascript
switch (grade) {
  case "F":
  case "D":
    console.log("You've failed!");
    break;
  case "C":
  case "B":
    console.log("You've passed!");
    break;
  case "A":
    console.log("Nice!");
    break;
  default:
    console.log("I don't know this grade.");
}
```

Для значений `F` и `D` происходит одно и то же действие — так же как для `C` и `B`. Если значение `grade` равно либо `C`, либо `B`, на экран будет выведен следующий результат:

```
You've passed!
```

Данный вариант более читабельный, чем альтернативный оператор `if else`:

```javascript
if (grade === "F" || grade === "D") {
  console.log("You've failed!");
} else if (grade === "C" || grade === "B") {
  console.log("You've passed!");
} else if (grade === "A") {
  console.log("Nice!");
} else {
  console.log("I don't know this grade.");
}
```

## FAQ

**Чем отличается `if` от `switch`?**

`if` подходит для оценки логических условий и сложных выражений, `switch` — для сравнения одного выражения с множеством конкретных значений. `switch` часто читается лучше при большом числе вариантов (четырёх-пяти и более).

**Почему в условии `if` нельзя писать один знак равно?**

Один знак `=` — это оператор присваивания, а не сравнения. В условии нужно использовать `===` (строгое равенство) или `==` (нестрогое равенство). Иначе значение будет присвоено, а не сравнено.

**Зачем нужен `break` в `switch`?**

`break` прерывает выполнение `switch` после выполнения подходящего случая. Без него управление «провалится» в следующий `case` и выполнит его код тоже (так называемое fall-through поведение).

**Что делает блок `default`?**

`default` выполняется, если ни один из `case` не совпал с выражением. Он аналогичен блоку `else` в конструкции `if else`.

**Когда использовать тернарный оператор?**

Тернарный оператор удобен для коротких действий с одним условием. Если логика содержит несколько сравнений или блоков кода, лучше использовать `if else`.

**Как объединить несколько случаев в `switch`?**

Нужно написать несколько `case` подряд без `break` между ними, а общий код разместить после последнего из объединяемых `case`:

```javascript
case "F":
case "D":
  console.log("You've failed!");
  break;
```

**Почему `switch` использует строгое сравнение?**

Оператор `switch` сравнивает значения с помощью `===`, то есть учитывает и значение, и тип данных. Поэтому `'1'` (строка) и `1` (число) — это разные случаи.
